# Changelog

All notable specification changes are documented here.

## [0.1.0] - 2026-10-25

### Added

- initial AWMM draft specification;
- JSON Schema Draft 2020-12 contract;
- Core, Migration-Ready and Evidence-Complete conformance levels;
- workload, environment, asset and dependency model;
- transformation and risk model;
- baseline and acceptance-gate model;
- evidence, provenance and rollback model;
- no-secrets security rule;
- ecosystem boundary documentation for MCP, A2A, Agent Skills, ALF, AAIF and runtime-specific migration mechanisms;
- reference semantic validator;
- representative migration examples;
- CI validation workflow.

### Status

Draft. No claim of industry-standard status or universal migration equivalence.
